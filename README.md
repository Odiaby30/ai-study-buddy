# AI Study Buddy

## Overview

AI Study Buddy is a full-stack web application that helps students study using Google's Gemini AI. Users can create an account, log in securely, ask study questions, and save their conversations.

## Features

- User Signup and Login
- Secure Session Authentication
- AI-powered Study Assistant using Gemini API
- Save Chat History
- Rename Saved Chats
- Delete Chats
- MongoDB Database Storage
- Responsive Web Interface

## Technologies Used

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- Google Gemini API
- HTML
- CSS
- JavaScript
- Render
- GitHub

## CRUD Operations

- Create: Save new AI conversations
- Read: View saved chat history
- Update: Rename saved chats
- Delete: Remove saved chats
